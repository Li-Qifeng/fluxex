## 未同步 — 高优先级（体验差距明显）

### 1. 剪贴板话题链接识别
- **Fluxdo**: v0.2.15 — 自动检测剪贴板中的 V2EX 链接，弹窗提示是否打开
- **FluxEx**: 无
- **实现**: `Clipboard.getData()` + 正则匹配 `v2ex.com/t/` + SnackBar 提示

### 2. 首页过滤子菜单（新/热门/全部 二级筛选）
- **Fluxdo**: v0.2.15 — 「新话题」筛选新增二级子过滤下拉，对齐网页版
- **FluxEx**: 首页只有单一 Tab，无二级筛选
- **实现**: 首页 TabBar 下增加 SegmentedButton（最新/热门/全部）

### 3. 通知分页
- **Fluxdo**: v0.1.31 — 通知列表分页支持
- **FluxEx**: 通知一次性加载，无分页
- **实现**: `SliverList` + `ScrollController` 监听到底加载更多

### 4. 图片查看器增强
- **Fluxdo**: v0.1.25/v0.1.28 — 长按菜单（保存/分享）、显示文件名、左右滑动切换
- **FluxEx**: `ImageGallery` 只有简单点击查看大图
- **实现**: `PageView` + `PhotoView` + 长按 `showModalBottomSheet`

### 5. 外部链接确认弹框
- **Fluxdo**: v0.1.21 — 点击外链前弹框确认，防止误触
- **FluxEx**: 直接 `launchUrl`，无确认
- **实现**: `showDialog` 显示目标 URL + 确认/取消按钮

### 6. 话题预览弹框（长按列表项快速预览）
- **Fluxdo**: v0.1.25 — 长按话题卡片弹出预览，显示更多信息 + 快捷分享
- **FluxEx**: 长按有菜单但无预览
- **实现**: `showModalBottomSheet` 展示话题摘要 + 操作按钮

## 未同步 — 中优先级（锦上添花）

### 7. 退出确认对话框
- **Fluxdo**: v0.1.28 — 返回键弹出「确认退出？」
- **FluxEx**: 无退出确认
- **实现**: `WillPopScope` / `PopScope` + `showDialog`

### 8. 新/未读筛选 + 一键已读
- **Fluxdo**: v0.1.23/v0.1.27 — 首页可筛选「未浏览」话题，新/未读排序下一键已读
- **FluxEx**: 无已读状态筛选
- **实现**: 本地已读记录 + 首页 FilterChip 切换

### 9. 编辑器插入 Callout / 模糊剧透
- **Fluxdo**: v0.2.15/v0.1.25 — 编辑器支持插入 callout 和模糊剧透
- **FluxEx**: V2EX 原生不支持（Discourse 专属）
- **结论**: ⚠️ V2EX 不支持，跳过

### 10. 用户签名显示
- **Fluxdo**: v0.2.15 — 帖子底部显示用户签名
- **FluxEx**: V2EX API 不返回签名字段
- **结论**: ⚠️ V2EX 不支持，跳过

### 11. 图片粘贴到编辑器
- **Fluxdo**: v0.1.21 — 编辑器支持直接粘贴图片
- **FluxEx**: 只有文件选择器，不支持粘贴
- **实现**: `Clipboard.getData('image/png')` 或 `Pasteboard` 插件

### 12. 发帖审核提示
- **Fluxdo**: v0.1.34 — 发帖后提示内容正在审核
- **FluxEx**: V2EX 无审核机制
- **结论**: ⚠️ V2EX 不适用，跳过

### 13. 话题关键词过滤
- **Fluxdo**: v0.2.16 — 按标题关键词过滤话题列表
- **FluxEx**: 无
- **实现**: 设置页添加关键词列表 + 首页过滤逻辑

## 推荐实施计划

### Phase 1 — 立即可做（无 V2EX API 限制）
1. **剪贴板链接识别** — 低成本高回报
2. **外部链接确认弹框** — 安全性提升
3. **退出确认对话框** — 防误触
4. **通知分页** — 大量通知时性能优化

### Phase 2 — 需要 UI 工作
5. **图片查看器增强** — 长按菜单 + 滑动切换
6. **首页二级筛选** — 最新/热门切换
7. **话题预览弹框** — 长按快速预览

### Phase 3 — 功能增强
8. **新/未读筛选** — 需要本地已读记录完善
9. **话题关键词过滤** — 设置页 + 过滤逻辑
10. **图片粘贴** — 需要平台特定实现
